# Evergreen Insurance Quote React Delivery

## Overview

This project was completed as part of the Full Stack Engineering (FSE) Leadership Capstone. The objective was to lead the delivery of a React + TypeScript application while applying delivery management, risk assessment, CI/CD practices, stakeholder communication, and release readiness decision-making.

## Technologies Used

- React
- TypeScript
- Vite
- GitHub Actions
- GitHub Pages
- Context API
- Custom React Hooks

## Features Delivered

- Quote calculator with premium estimation
- Recent Quotes data feed integration
- Loading, error, and success states
- Save Quote functionality using Context Provider
- TypeScript validation
- GitHub Actions CI workflow
- Production build validation
- Pull request review and merge process

## Risk & Incident Management

During the capstone, project risks were actively identified and managed, including:

- TypeScript validation failures
- Component integration issues
- Data feed availability concerns
- CI/CD pipeline failures
- Production build and release readiness risks
- Dependency audit findings
- Customer-facing pricing/configuration issues

The project also included simulated stakeholder requests and incident scenarios requiring reprioritization, investigation, stakeholder communication, and release-readiness decisions.
